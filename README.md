## ✨ Key Features
- **🦈 MrBeast-Style Shark Branding:** Electric cyan shark vector logo with razor teeth and neon pink lightning bolt.
- **⚡ Gemini Dynamic Neural Aura:** Real-time continuous laser light sweep and ambient pulse across the entire UI.
- **💎 Executive 3-Card Spotlight Banner:** Structured cards displaying developer identity, institution, and degree.
- **💳 Integrated Secure Payment Gateway:** Real-time BHIM UPI QR Code, Credit/Debit cards, Net Banking, and automated PDF invoice generation.
- **🔒 Multi-Layer Anti-Copy Protection:** Text selection lock (`user-select: none`), clipboard copy interception, and real-time warning toasts.
- **📊 Real-time Productivity & Analytics:** Interactive burndown charts, Kanban sprint boards, and autonomous task decomposition.

## 🚀 Getting Started Locally

```bash
# 1. Clone repository
git clone https://github.com/your-username/nexora.git

# 2. Navigate to project
cd nexora

# 3. Install dependencies
npm install

# 4. Start local development server
npm run dev

# 5. Build for production
npm run build
```
